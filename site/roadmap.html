ROADMAP /

Ambitious by design.
Built in increments.

The goal is one workstation as good as the best standalone app in each area, with everything wired together. Nothing below the first block is shipped.

BUILT

On the integration branch today.

Verified in the app or by tests at the time of writing; see the activities page for limits.

  • Ten activities declared in one registry, each tied to agent tools or a written reason it has none
  • Agent loop with Ask, Auto and Bypass approvals, context compaction, audit chain and MCP server
  • Develop editor with language server, build, test and an LLDB launch debugger
  • Analyze with native inspection and optional Ghidra, Lab with Create ML and MLX training, Browser, Devices and Media
  • Voice, plus iPhone and Apple Watch companions built from source
IN PROGRESS

Being built in parallel. Not shipped.

These live on separate branches. None has been merged or seen working in the released app, so treat them as plans.

  • Image studio. A catalog of open image models, resumable downloads into the model store, and engines behind one protocol: in-process on Apple silicon, or an installed Draw Things, ComfyUI or AUTOMATIC1111/Forge. Agent and MCP image tools. A missing backend will show a setup state, never fake output.
  • Agent platform. Slash commands, hooks, memory files, plan mode, checkpoints and rewind, a sessions list, a usage and cost view, and editable permission rules.
  • Communications and schedule. Mail, Contacts, Messages, Calendar and Reminders, and read-only GitHub pull requests and CI, plus Shortcuts for every activity and an “Ask Kiln” shortcut. Built and tested against fakes; not yet tried with real accounts. Messages relies on interfaces Apple does not document, so it can break with a macOS update.
  • Develop and Analyze upgrades. Toward an Xcode and Ghidra bar: symbol outline, refactoring, debugger variables and threads, graph view, structure editor, patching and binary diffing.
NEXT

Make the foundation dependable.

Streaming that feels immediate, correct tool execution, clear failures, reliable saving, cancellation and artifact reload.

  • Agent streaming and provider responsiveness, with visible end-to-end checks
  • Agent tools for the registry gaps: swarm control, audit queries, build and debug, project selection
  • Model-specific tool reliability and honest task completion
  • Companion apps that stay reachable in the background
  • Accessible navigation and polished narrow-window layouts
  • Next integrations, in this order: Spotlight indexing, PDF annotation and a research library, cloud drives, Notes, Slack and chat connectors, Notification Center and Focus, a menu-bar quick-ask and Share extension, Writing Tools, weather with a radar layer on the Maps view, and a document, spreadsheet and presentation studio
HORIZON

Go beyond parity.

Ideas that suit a suite where everything shares one audit trail. Each is a proposal, not a commitment.

  • Evidence ledger and signed, replayable run bundles
  • Pinboard: pin a function, string, page selection or device frame into the agent’s context with provenance
  • Saved workflows across modules, a verifier agent, privacy tiers with local-first routing, and policy as code
  • Closed-loop app analysis: run an app in a simulator and link observed behavior to decompiled functions
WAITING

Depends on someone else.

Not promised, and not implemented as features.

  • Passkeys in the Browser need an Apple entitlement that has been requested and not granted; password autofill is untested
  • iCloud sync, push for new features and Apple Private Cloud Compute are not verified in any build; the Private Cloud Compute provider is in development and untested
  • Windows and Linux guests in Devices are a design only

Help define what comes next.

We welcome proposals with concrete user scenarios, clear tradeoffs, and a way to verify the result. No promised dates; progress is tracked in public issues. The full list, with the bar for each module, is in Parity and beyond.
