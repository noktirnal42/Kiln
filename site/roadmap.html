ROADMAP /

Ambitious by design.
Built in increments.

The goal is one workstation as good as the best standalone app in each area, with everything wired together. Nothing below the first block is shipped.

BUILT

In the current source on main.

Verified in the app or by tests at the time of writing; see the activities page for limits. The published preview (0.1.1) is far behind the source.

  • Home, Agent, Swarm, Develop, Analyze, Lab, Audit, Browser, Devices, Media, Images, Maps and News, declared in one registry, each tied to agent tools or a written reason it has none
  • Agent loop with Ask, Auto and Bypass approvals, context compaction, audit chain and MCP server; tools loaded on demand to save context, and a browser that identifies as Safari
  • Agent platform: slash commands, hooks, memory files, plan mode, checkpoints and rewind, sessions, usage and cost, and scheduled tasks
  • Develop editor with language server, build, test and an LLDB launch debugger; Analyze with native inspection and optional Ghidra; Lab with Create ML and MLX training
  • Voice, plus iPhone and Apple Watch companions built from source
DEV BUILDS

Built, not yet tried with real data.

These are merged and their empty states and permission screens have been seen on screen, but they were built and tested against fakes, fixtures and generated files. Calendar has read real events; nothing else has met a real account, mailbox or folder.

  • Communications and schedule. Mail, Contacts, Messages, Slack, Calendar and Reminders, plus Shortcuts for every activity and an “Ask Kiln” shortcut. Messages relies on interfaces Apple does not document, so it can break with a macOS update.
  • Knowledge. Research (PDF annotation, a library and citations), Cloud Drives, Notes, read-only GitHub pull requests and CI, and opt-in Spotlight indexing of conversations.
NEXT

Make the foundation dependable, then the next integrations.

Streaming that feels immediate, correct tool execution, clear failures, reliable saving, cancellation and artifact reload.

  • Agent streaming and provider responsiveness, with visible end-to-end checks
  • Agent tools for the registry gaps: swarm control, audit queries, project selection
  • Reasoning levels that follow what each model offers, and a less crowded chat bar
  • Model-specific tool reliability and honest task completion
  • Companion apps that stay reachable in the background
  • Accessible navigation and polished narrow-window layouts
  • Next integrations, in this order: weather with a radar layer on the Maps view, and a document, spreadsheet and presentation studio
  • Develop and Analyze upgrades toward an Xcode and Ghidra bar; much of the service layer exists and many of the new views have not been seen in the running app
HORIZON

Go beyond parity.

Ideas that suit a suite where everything shares one audit trail. Each is a proposal, not a commitment.

  • Evidence ledger and signed, replayable run bundles
  • Pinboard: pin a function, string, page selection or device frame into the agent’s context with provenance
  • Saved workflows across modules, a verifier agent, privacy tiers with local-first routing, and policy as code
  • Closed-loop app analysis: run an app in a simulator and link observed behavior to decompiled functions
WAITING

Depends on someone else.

Not promised, and not implemented as features.

  • Passkeys in the Browser need an Apple entitlement that has been requested and not granted; password autofill is untested
  • iCloud sync, push for new features and Apple Private Cloud Compute are not verified in any build; the Private Cloud Compute provider is in development and untested
  • Windows and Linux guests in Devices are a design only

Help define what comes next.

We welcome proposals with concrete user scenarios, clear tradeoffs, and a way to verify the result. No promised dates; progress is tracked in public issues. The full list, with the bar for each module, is in Parity and beyond.
