ROADMAP /

Ambitious by design.
Built in increments.

The goal is a cohesive native workstation. Here is the work between the foundation and that vision.

NOW

Make the foundation dependable.

Streaming that feels immediate. Correct tool execution. Clear failures. Consistent layouts. Reliable saving, cancellation, and artifact reload.

  • Agent streaming and provider responsiveness
  • Real workflow regression coverage
  • Model-specific tool behavior and honest task completion
  • Companion apps that stay reachable in the background, with push notifications for approvals
NEXT

Connect the whole workshop.

Expose more app actions through the same services used by the GUI, agents, swarms, and external MCP clients.

  • Training, evaluation, export, and experiment control as agent actions
  • Shared project context across every workspace
  • Computer use beyond reading: screenshots, keyboard and scrolling, with per-action approval
  • Accessible navigation and polished narrow-window layouts
HORIZON

Go deeper in every discipline.

Build an editor and project workflow worth staying in. Strengthen reverse engineering. Make model creation comprehensible and reproducible.

  • Source editing, language services, build/debug workflows
  • Ghidra integration and richer binary navigation
  • Training pipelines, evaluation, and artifact portability

Help define what comes next.

We welcome proposals with concrete user scenarios, clear tradeoffs, and a way to verify the result. No promised dates; progress is tracked in public issues.
