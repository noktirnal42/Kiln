Security policy ↗
Where is the download?

A notarized preview build (0.1.1) is on the GitHub Releases page, with checksums and notes on what was and was not verified. It is a preview, not a stable release. You can also build from source with the documented steps.

Do I need a paid model account?

No single provider is required. Local Ollama and Apple Foundation Models are options when available. Hosted providers may charge separately and can reject requests because of account limits.

Why does a model fail to use tools?

Provider connectivity and tool reliability are different. Smaller models can emit simulated calls, repeat actions, or miss instructions. Include the exact provider and model in your report.

Does Kiln replace Xcode or Ghidra?

Not today. Kiln combines working foundations with an ambitious roadmap. Develop does not yet have a full source editor or debugger, and advanced Ghidra recovery requires a configured installation.

Can the agent use every feature?

Not yet. Agents can use shared file, shell, Git, RE, and selected Model Lab actions. Expanding safe, service-backed feature access is a tracked contribution area.
