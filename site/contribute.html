Make a focused contribution

  1. Read the contribution guide and pick a concrete issue.
  2. Describe the user problem and your proposed approach.
  3. Build a focused change using shared services.
  4. Verify behavior and include visual evidence for UI changes.
  5. Open a pull request with results and remaining limits.

WHAT WE VALUE

Evidence.
Care.
Good judgment.

Real examples over canned demos. Native Mac behavior. Useful accessibility. Clear ownership. Honest claims about what passed and what still needs work.

Kiln is source-available under the PolyForm Noncommercial License, and contributions are accepted under the contributor agreement (CLA.md). Contributions should include only work you have the right to share, with appropriate attribution for dependencies.

SUPPORT THE WORK

Help keep the kiln warm.

Funding can support development time, test hardware, model-provider testing, and documentation. Kiln is free for noncommercial use, and sponsorship is entirely optional. A reproducible issue, a thoughtful review, or a focused pull request is just as valuable as money.
