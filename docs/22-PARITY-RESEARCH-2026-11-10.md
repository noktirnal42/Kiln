## Beyond coding agents

Microsoft describes document, spreadsheet and presentation editing, plus connected work sources; availability varies by account and plan. Perplexity describes computer/browser workflows and multiple task tabs. These are relevant benchmarks for an everything workstation, not evidence of Kiln parity. [Microsoft Office editing](https://support.microsoft.com/en-us/office/copilot-frontier/get-started-editing-with-copilot-in-office), [Microsoft data sources](https://support.microsoft.com/en-us/excel/copilot/copilot-in-excel-data-sources), [Perplexity app updates](https://www.perplexity.ai/changelog/automations-inline-visualizations-and-gpt-6-1-sol)

Kiln needs real document and workbook round trips, source selection and per-connection consent, a trustworthy research library, visual artifact review, and multiple inspectable task sessions. Evaluate whether it can produce an accurate, editable report from selected feed entries and map records, with citations and without sharing hidden data. Treat file-format fidelity, citations and permission boundaries as acceptance criteria.

## A defensible path beyond parity

1. **Prove the foundation:** finish the tracker: streaming/Stop, reliability for small models, real Ghidra cancellation, editor keyboard/VoiceOver, device lifecycle, Model Lab end-to-end training, and reproducible release/CI. Track pass/fail by scenario, runtime and actual artifact.
2. **Create a shared substrate:** a permission-aware Pinboard for artifacts and sources, stable IDs and citations, a searchable local project index, data lineage and signed exportable run bundles. Make context, source and destination visible before every action.
3. **Build composable workflows:** connect Maps, research, Browser, Lab, Develop and Media using typed steps, resumable state, human checkpoints, budgets, reproducible inputs, provenance and explicit failure paths. Provide an inspectable agent and MCP action for every useful operation.
4. **Win on specialist depth:** a geospatial investigation can discover a historical sheet, preserve metadata, compare it with current terrain, analyze related imagery and produce a cited document. Technical investigations can combine binary analysis, debugger, device lab and evidence. Validate complete tasks, not screenshots or checklists alone.
5. **Measure:** define a public, repeatable task suite with fixed fixtures, baseline apps and versions. Measure completion, correctness, recovery, cost, latency, accessibility and number of interventions. A comparison is not a victory claim until independent tests support it.

Further candidate activities and the Maps design are in [the product roadmap](21-EVERYTHING-APP-ROADMAP.md). Prioritize user workflows and reliability over activity count; do not ship placeholder tabs.

## News: improvements toward a complete reader

The first News view provides a source directory, subscriptions, a combined feed and filtering. To approach a mature reader, add persistent articles and read/unread/starred state; folders and smart topic rules; OPML import/export; feed discovery from websites; conditional and scheduled refresh with progress and backoff; article deduplication across sources; full-text extraction where permitted; offline caching; media enclosures; better accessibility and keyboard navigation; bounded network downloads; and source health diagnostics. Agent and MCP actions should use the same stores, expose filterable results with source/date metadata, and retain approval for network access and edits. Validate with RSS, Atom, RDF, JSON Feed, malformed feeds and real publishers; do not claim a feed's availability from its presence in a directory.

Maps needs editable and durable pins, walking/cycling/transit options where supported, route steps and alternatives, saved areas, measured distances, coordinate entry, geospatial exports, historical sheet overlays with verified projections, elevation, offline policy and source attribution. Test real OS location permission, denied/restricted paths, directions and service outages before claiming navigation parity.

## Standalone map and reader benchmarks

Apple Maps documents driving, walking, transit and cycling directions, alternate routes, multi-stop driving, saved places and hikes; availability varies by region. Gaia GPS documents route editing and offline, layered map downloads, including membership-dependent capabilities. These are benchmarks, not claims about Kiln. [Apple directions](https://support.apple.com/en-eg/guide/maps/mps4d8a6bd2f/mac), [Apple Maps guide](https://support.apple.com/en-euro/guide/maps/welcome/mac), [Gaia route editing](https://help.gaiagps.com/hc/en-us/articles/115003523607-Create-Edit-and-Measure-Routes-in-the-iOS-App), [Gaia offline layers](https://help.gaiagps.com/hc/en-us/articles/360047131513-Download-Maps-for-Offline-Use)

Kiln's initial implementation needs a configurable origin, travel modes, alternatives, multiple stops, persistent and editable pins, route/export history, keyboard-accessible map actions, resilient source and location errors, measured distance and area, actual historical sheet rendering, offline rights and downloads, and physical-device testing. Its current directions use the map center and a single driving route; Terrain uses MapKit's realistic elevation configuration, and USGS Topo is a separate current-data layer. Measure against documented workflows and real inputs before claiming parity.

ModernReader's standalone library contains source discovery, conditional fetching, OPML, persistent library storage and article state; Kiln currently reuses its parser and directory but not the complete standalone workflow. Prioritize those missing controls and persisted state, safe feed download limits, duplicate handling, search and keyboard accessibility; then add agent/MCP equivalents and round-trip tests.
