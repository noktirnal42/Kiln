# Kiln 0.1.1 (preview)

A patch release on top of 0.1.0. **Upgrade if you plan to use voice:** 0.1.0 quits the first time voice asks for Speech Recognition permission.

## Fixed

- **Voice crash on first use.** macOS answers the Speech Recognition permission request on a background thread, and Kiln had marked its callback as main-thread-only, so the app was terminated. Fixed on the Mac (dictation and conversation mode, and recordings transcribed for the Apple Watch) and in the iPhone app's microphone.
- **Computer use could not send a message.** It typed into a chat field with a value setter, which apps like Messages do not count as typing, so Send never activated. Computer use now has real keyboard actions (`activate`, `focus`, `type_text`, `key`) limited to navigation, confirmation and a few command shortcuts, and it refuses to type into password fields.
- **Runs that ended with no answer showed nothing.** The chat now says the model stopped without an answer, how many steps it ran and how the last one ended, and it does not claim the task is done.
- **Remote-control link stability.** Keepalive pings on the Mac's relay link and on the watch's link, so a link that dies silently is noticed and reconnected. A fixed port (47900) is tried first and any free port is used when it is taken.

## New

- **Approval alerts through Apple push.** When an approval has waited about 4 seconds, the Mac asks your relay to alert your iPhone (it mirrors to a paired watch). Allow once and Deny work from the notification, even if the app was closed. Needs a one-time Apple push key and a relay you host: see `docs/14-REMOTE-CONTROL.md`. The alert shows the tool, its access level and the start of the command; a switch in the Remote control card turns the command text off.
- **Computer use settings** show whether this copy of Kiln is trusted for Accessibility, explain the stale-entry trap, and can relaunch Kiln.
- **iPhone app:** an Approval alerts section (notification permission, push token, whether the Mac knows the phone) and a Stay connected when locked switch.
- **Watch:** Talk records at once and the Mac transcribes it, with no system dictation sheet; the relay is tried first over a connection watchOS carries through the paired iPhone.

## Verified, and not

Verified on real hardware (2026-11-03): an Ask-mode approval raised at the Mac was answered from a push alert with the phone locked (`approvals.jsonl`: `via: remote`); the watch dictated a message that reached the Mac and was spoken back; Kiln's agent read Calendar and Messages through computer use.

Not verified: Messages sending with the new keyboard actions in a recorded run, alert delivery latency over many alerts, production-signed push tokens, Auto approval mode in a real agent run, voice accuracy. The iPhone and watch apps are not in this download: build them from `Companion/` with your own signing team. Everything in the 0.1.0 notes about limits still applies.
