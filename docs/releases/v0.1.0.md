# Kiln 0.1.0 (preview)

The first downloadable build of Kiln: a native Swift and SwiftUI Mac workstation for AI agents, development, reverse engineering and model experimentation. **It is early-stage software.** Expect rough edges, and read the limits below before relying on it.

## Download and install

- `Kiln-0.1.0.dmg` (or the `.zip`): open it and drag Kiln to Applications. Verify with `shasum -a 256 -c Kiln-0.1.0.sha256`.
- The app is **Developer ID signed, notarized by Apple and stapled**. Requires macOS 15 or later; Apple silicon is recommended for MLX.
- Kiln is **not sandboxed** on purpose: its agent runs real git, package managers and shells. Approvals, policy gates, behavior-monitor holds and an audit chain are the safety layer. Read `docs/11-CURRENT-STATE.md` first.
- Your data lives in `~/Library/Application Support/Kiln`. There is no in-app updater: download the next build and replace the app.

## What is in it

- Chat with local and hosted providers; an agent with tools (files, shell, git, search, MCP), approvals, a behavior monitor and a tamper-evident audit chain; role-based swarms.
- A source editor with a Swift/C language server, build/test/run, an LLDB launch debugger, code folding, multi-cursor and Git gutter.
- Binary analysis (native Mach-O inspection, radare2 and Ghidra engines) and Model Lab (Create ML, MLX fine-tuning, distillation, small-LM training), several of them also as agent tools.
- Voice in the composer: dictation, spoken replies and a hands-free conversation mode.
- Approval modes: **Ask**, **Auto** and **Bypass**. They reset on launch, never create standing grants, and every decision is logged with how it was answered.
- Remote control for an iPhone and an Apple Watch companion (source in `Companion/`): chat, speak to the agent and allow or deny its tool calls over an encrypted link, on the local network or through a relay you host (`Relay/`).
- Experimental computer use (Accessibility based), off until you enable it in Settings.

## What was verified

- The full Mac test suite (592 tests) passes.
- On real hardware: the Apple Watch dictated to the Mac through the iPhone and the reply was spoken; allow and deny from the phone and the watch reached the Mac and were logged as remote; a relay deployed on Cloudflare carried a watch message to the Mac; Kiln's own agent read Calendar and Messages through computer use; a LoRA fine-tune and a distillation ran end to end through the agent tools.

## What was not verified, and known limits

- The iPhone and watch apps are **not in this download**: build them from `Companion/` with your own signing team. Closed or backgrounded companion apps cannot receive approval alerts until push notifications exist (they need an Apple push key). The iPhone's "stay connected when locked" mode keeps the app alive with silent audio; it uses battery and is not App Store compatible.
- Locked-phone and long-background behavior of the companions is still being tested. All paired devices share one key; "Unpair all devices" is all-or-nothing.
- Computer use reads and operates other apps through Accessibility only: no screenshots, keyboard or scrolling yet. It sees only what an app exposes. macOS keeps a stale "Kiln: on" Accessibility entry for builds signed differently, so remove it and add the installed app.
- Auto approval mode is unit-tested but has not been run by a real agent. The editor is not Xcode: no previews, debugger attach or other language servers. Ghidra needs setup. Small local models can fail tool use.
- Voice has not been measured for accuracy, and replies are spoken after they finish rather than while streaming.
