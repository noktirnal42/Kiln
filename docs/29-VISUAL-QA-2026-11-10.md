## Bug found and fixed during QA

**`NewsState.refresh(_:)` corrupted the sources-list selection.**

`NewsService.swift` set `selected` to a human-readable value:

```swift
selected = value == Self.all ? "All stories" : (names.first ?? "News")
```

Because the sources `List(selection: $state.selected)` tags rows with the source URL,
this broke selection and the `onChange(of: state.selected)` handler re-invoked
`refresh()` with a display name, which failed the guard and surfaced
"Select a subscribed source first." while clearing the fetched articles.

Fix: keep `selected` as the exact source tag; only set the human-readable title.

```swift
if value == Self.all { selected = Self.all }
title = value == Self.all ? "All stories" : (names.first ?? "News")
```

Verified after rebuild: clicking a subscription fetches and displays articles.
