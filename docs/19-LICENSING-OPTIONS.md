# Licensing options for Kiln

Research for an owner decision, 2026-11-09; this is not a license change. The current repository
uses MIT, copyright Kiln contributors. Existing MIT releases remain available under their granted
terms. Git authorship is not proof of copyright ownership or authority to relicense; review
contributions, agreements, dependencies and distributed artifacts with counsel first.

| Approach | Commercial effect | Tradeoff |
| --- | --- | --- |
| MIT core plus paid proprietary additions, support or hosted service | Monetizes new features and services while keeping the core open | Existing MIT code remains freely reusable; paid additions must be separable and properly owned |
| AGPL for eligible future code plus a separate commercial license | Can create a paid option for customers who need different terms; modified network deployments have source-offer obligations | Still permits commercial use; prior MIT versions remain available, and dual licensing requires necessary rights |
| Source-available commercial / noncommercial terms for eligible future code | Can reserve specified commercial uses for paid agreements | Not open source under the OSI definition; may deter contributors and create dependency compatibility issues |

A practical first evaluation is an MIT core with paid, separately owned additions or services;
compare its revenue potential with AGPL/commercial dual licensing after an ownership and dependency
audit. Consider a contributor agreement for future contributions, a trademark policy, pricing and
distribution strategy. No approach guarantees revenue. Do not replace the current license or
represent past MIT grants as revoked without legal review.

Sources: [Open Source Initiative definition](https://opensource.org/osd),
[GNU AGPL FAQ](https://www.gnu.org/licenses/gpl-faq.html),
[Open Source Guides: legal](https://opensource.guide/legal/), and
[Cambridge: licensing software](https://www.openresearch.cam.ac.uk/copyright-licensing-citation/software-code).
