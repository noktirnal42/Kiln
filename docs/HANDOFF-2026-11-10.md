## 6. Pitfalls found the hard way

- **Same bundle id, several Debug builds.** `com.kiln.app` is shared by every worktree build and by XCTest hosts. The
  computer-use tools attach to whichever instance they find first, so a session can drive the wrong app. Under XCTest,
  `ChatSession` deliberately has no schedule, usage, checkpoint or memory stores and registers stub providers
  (`stub-m1`), so a test host shows empty or odd screens. Before GUI checks run `pgrep -fl "Contents/MacOS/Kiln"`,
  make sure only your build runs, and check that the status bar shows a real model, not `stub-m1`.
- **Concurrent test suites collide.** RE tests import the same system binary into a shared project store and fail with
  "Choose a new project folder; this path already exists". If one session runs a suite while another does, expect it;
  rerun the failing suite alone (`-only-testing:KilnTests/<Suite>`). Run the full suite only when nothing else builds.
- **Worktrees start from `main`.** `start_session` cuts them from `main` unless you pass `source_branch`. Pass the
  integration branch, and tell sessions to `git merge` it before they start.
- **Shared merge hot spots** were `WorkstationModel`, `MainWindow`, `WorkstationSidebar`, `AppModel`, `AgentProfile`,
  `ExecutionPolicy`; the registry removed most of that. Docs (`11-CURRENT-STATE`, `13-AGENT-CAPABILITY-MATRIX`) still
  conflict by both sides appending rows; resolve by keeping both.
- **Usage limit is shared by every session.** At 100% of the 5-hour window all sessions stop, and finished-looking
  sessions may simply be blocked. Check `get_usage` before assuming idle means done.
- **Background automation typing** inserts at the caret: click the field, then type the whole text in one call
  (clicking, typing "/" and then "hooks" produced `hooks/`). Password fields are never touched; scroll from a
  non-field point. Use `app_click` with an element index or coordinates from the latest screenshot.
- **Package.resolved**: never commit it. **Xcode UI edits to signing** are overwritten by `xcodegen generate`; change
  `project.yml` instead.
- **Public wording**: Kiln is *source-available*, not open source. `Scripts/relicense-references.sh` rewrites
  stale "MIT/open source" wording; rerun it after any large docs change. `Scripts/check-docs.sh` validates links,
  anchors, privacy (personal paths, emails, tokens, local build paths) and the README License section.
